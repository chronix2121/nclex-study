Mock NCLEX (adaptive)

Modeled on NCLEX-RN computerized adaptive testing: each answer updates an ability estimate (Rasch model), the next item is chosen near that estimate, and Client Needs areas are balanced to the test plan. Case studies appear as 6-item units. The exam stops when the 95% confidence interval is fully above or below the passing standard (after the minimum length), at the maximum length, or when time runs out. There is no going back, and no feedback until the end.

Guided reading - no questions found in this file, so work through the 6 clinical judgment steps. Notes save automatically on this device.

Big JSON banks (thousands of items) are fine - they are stored in this browser's IndexedDB. Duplicate item ids are skipped, so re-importing is safe. Files with questions are added to the bank. Files with only a case (no questions) open in guided reading mode. You can also paste below.

Text format reference 
CASE: Client with DKA
SOURCE: (optional) where it came from
SCENARIO: intro text
NOTES: nurses' notes (lines continue until the next keyword)
VITALS: Time | HR | BP          (use | for table columns)
LABS: Test | Result | Reference
ORDERS: one order per line

Q: Which prescription should the nurse implement first?
AREA: Pharmacological and Parenteral Therapies   (optional Client Needs area)
STEP: Prioritize Hypotheses                      (optional clinical judgment step)
DIFFICULTY: 3                                    (optional 1-5, default 3)
A. Regular insulin IV infusion
B. 0.9% sodium chloride 1 L IV
ANSWER: B          (letters A=1, B=2...; options display as 1, 2, 3; several letters = select all that apply, +/- scoring)

Q: In what order should the nurse...?
TYPE: ORDERED
A. ...  B. ...  C. ...
ANSWER: B, A, C    (correct order, first to last; exact order scoring)
RATIONALE: ...

Q: For each finding, indicate ...
TYPE: MATRIX
COLUMNS: Expected | Requires follow-up
ROW: Pain 4/10 = Expected

Q: Complete the sentence.
TYPE: CLOZE
TEXT: The client is at risk for {1} because of {2}.
BLANK 1: hypokalemia * | hypernatremia      (* marks the correct option)
BLANK 2: furosemide * | metoprolol

Q: Click to highlight the findings that require follow-up.
TYPE: HIGHLIGHT
TEXT: [[RR 8/min]] [Dressing dry]   ([[ ]] = correct phrase, [ ] = selectable distractor)

KIND: standalone   (on a CASE line block: items are served one by one, not as a unit)

JSON: {"cases":[{"title","scenario","exhibits":{"notes","vitals","labs","orders"},"kind","items":[{"type":"single|sata|matrix|cloze|highlight|ordered","q","options","answer","columns","rows":[{"label","answer"}],"text","blanks":[{"options","answer"}],"area","step","difficulty","rationale"}]}]}
